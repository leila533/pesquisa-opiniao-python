# pesquisa-opiniao-python
Projeto em Python que realiza uma pesquisa de opinião para a empresa TudoWeb. O programa coleta nome, idade e avaliação do atendimento (Excelente, Bom ou Ruim) de 50 entrevistados. Utiliza estrutura de repetição for e decisões if/elif para processar os dados e exibir a quantidade de respostas Excelente e Ruim ao final.
