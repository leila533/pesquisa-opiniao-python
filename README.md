## 📌 Descrição
Este projeto foi desenvolvido em Python com o objetivo de simular uma pesquisa de satisfação para a empresa fictícia **TudoWeb**.

O sistema coleta dados de **50 entrevistados**, solicitando:
- Nome
- Idade
- Avaliação do atendimento

As opções de avaliação são:
- ✅ 1 - Excelente  
- 👍 2 - Bom  
- ❌ 3 - Ruim  

Ao final, o programa exibe o total de respostas **Excelente** e **Ruim**.

---

## 🎯 Objetivo do Projeto
Aplicar conceitos fundamentais de programação, como:
- Estrutura de repetição (`for`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Entrada e saída de dados
- Contagem e processamento de informações
